# Autovalor dominante

## Definición

$\lambda_1$ es **dominante** si $|\lambda_1|>|\lambda_i|$ para todos los demás autovalores (contando multiplicidad): es necesariamente simple. Es el que encuentra el método de las potencias, con tasa $|\lambda_2/\lambda_1|$. Puede no existir: si una matriz real tiene autovalor de módulo máximo complejo, su conjugado tiene el mismo módulo; tampoco existe si hay $\pm\lambda$.
