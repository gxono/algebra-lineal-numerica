# Problema 5.12 - Multigrid como método iterativo: tests y verificación

## Enunciado

> (Multigrid como método iterativo.) Implementar en matlab/octave las funciones `jacobiamortiguado`, `restringir`, `prolongar` y `vciclo` de la Sección 5.7. Para los experimentos, tomar $n=2^L-1$ y $h=\frac1{n+1}$, elegir un vector $u_*\in\mathbb R^n$ cualquiera (por ejemplo, $(u_*)_i=x_i(1-x_i)\text{sen}(\pi x_i)$, o un vector aleatorio) y definir $f=A_hu_*$. De este modo se conoce exactamente la solución del sistema discreto $A_hu=f$, y se puede medir el error verdadero y no solo el residuo.
> **(a)** Test de consistencia. Verificar que si se parte de $u=u_*$, un ciclo en V devuelve $u_*$ (a menos de error de redondeo). Explicar por qué esto tiene que ser así, y por qué es una buena manera de detectar errores de programación.
> **(b)** Test de la relación variacional. Construir las matrices de $I_{2h}^h$ e $I_h^{2h}$ aplicando las funciones a los vectores de la base canónica, y verificar numéricamente la identidad (5.23).
> **(c)** Partiendo de $u=0$, iterar $u\leftarrow\text{vciclo}(u,f,h,\nu,\nu)$ hasta que $\dfrac{\|f-A_hu\|_2}{\|f\|_2}<10^{-10}$, con $\nu=1$. Registrar la cantidad de ciclos necesarios para $L=5,6,\dots,11$. ¿Crece con $n$?
> **(d)** Calcular, en cada ciclo, el cociente $\dfrac{\|r_{k+1}\|_2}{\|r_k\|_2}$. Verificar que se estabiliza en un valor $\rho$ que casi no depende de $h$, y comparar los valores de $\rho$ obtenidos con $\nu=1,2,3$. Contrastar con el Teorema 5.34.
> **(e)** Comparación con el suavizador solo. Repetir el ítem (c) usando únicamente `jacobiamortiguado` (es decir, sin corrección en malla gruesa), con una tolerancia más modesta como $10^{-6}$ y valores chicos de $L$. Verificar que la cantidad de barridos crece como $O(n^2)$, y explicar la diferencia a la luz de la propiedad de suavizado.

$n=2^L-1$, $u_*$ elegido (ej. $(u_*)_i=x_i(1-x_i)\text{sen}(\pi x_i)$), $f=A_hu_*$ (así se conoce la solución exacta). Las funciones `jacobiamortiguado`, `restringir`, `prolongar`, `vciclo` están explicadas con más detalle en [[Multigrid en 1D - transferencia e implementacion]] - acá van completas, para que este bloque corra solo, sin tener que ir a buscarlas a otro lado:

```julia
function jacobiamortiguado(u, f, h, nu)
    u = copy(u)   # no muta el argumento de entrada (sin !, no debe mutar)
    n = length(u)
    ω = 2/3
    for _ in 1:nu
        Au = (2u .- [u[2:n];0] .- [0;u[1:n-1]]) / h^2
        u .+= ω * (h^2/2) .* (f .- Au)
    end
    return u
end

function restringir(r)
    n = length(r)
    nc = (n-1)÷2
    return [(r[2j-1] + 2r[2j] + r[2j+1])/4 for j in 1:nc]
end

function prolongar(vc)
    nc = length(vc)
    n = 2nc+1
    vext = [0; vc; 0]
    v = zeros(n)
    v[2:2:n-1] = vc
    v[1:2:n] = [(vext[j+1]+vext[j+2])/2 for j in 0:nc]
    return v
end

function vciclo(u, f, h, nu1, nu2)
    n = length(u)
    n == 1 && return f * h^2 / 2        # malla más gruesa: A_h es escalar 2/h²
    u = jacobiamortiguado(u, f, h, nu1)         # (1) pre-suavizado
    Au = (2u .- [u[2:n];0] .- [0;u[1:n-1]]) / h^2
    r = f - Au                                   # (2) residuo
    rc = restringir(r)                           # (3) restricción
    ec = vciclo(zeros(length(rc)), rc, 2h, nu1, nu2)   # (4) corrección (recursiva)
    u += prolongar(ec)                           # (5) prolongación y corrección
    u = jacobiamortiguado(u, f, h, nu2)          # (6) post-suavizado
    return u
end

function Ah(N)                      # matriz tridiagonal del problema modelo (ver [[5.5 - Comparacion metodos sistema 1D|Problema 5.5]])
    h = 1/(N+1)
    SymTridiagonal(fill(2/h^2, N), fill(-1/h^2, N-1))
end

function uexacta(N)                 # (u_*)_i = x_i(1-x_i) sen(π x_i), en los N nodos interiores
    h = 1/(N+1)
    [(i*h)*(1-i*h)*sin(π*i*h) for i in 1:N]
end
```

*(Las cuatro primeras funciones son exactamente las de [[Multigrid en 1D - transferencia e implementacion]]; `Ah` y `uexacta` son auxiliares de este problema puntual, para armar un sistema de prueba con solución exacta conocida.)*

## (a) Test de consistencia

```julia
N = 63
h = 1/(N+1)
A = Ah(N)
u_exacto = uexacta(N)
f = A * u_exacto
u = vciclo(copy(u_exacto), f, h, 1, 1)
norm(u - u_exacto)   # debería dar ≈0 (orden de redondeo)
```
**Debe dar $≈0$:** partiendo del error nulo, el ciclo en V no puede *crear* error - si $u=u_*$ exactamente, el residuo $r=f-A_hu_*=0$, la corrección gruesa resuelve $A_{2h}e_{2h}=0 \Rightarrow e_{2h}=0$, y todo el ciclo deja $u$ intacto. Es una excelente manera de **detectar bugs**: si este test falla, hay un error de implementación (típicamente en los índices de `restringir`/`prolongar`).

## (b) Test de la relación variacional

```julia
N = 15
nc = (N-1) ÷ 2
function canonico(n, j)   # j-ésimo vector de la base canónica, en Rⁿ
    e = zeros(n)
    e[j] = 1.0
    return e
end

I2h_h = hcat([prolongar(canonico(nc, j)) for j in 1:nc]...)    # matriz de prolongar
Ih_2h = hcat([restringir(canonico(N, j)) for j in 1:N]...)     # matriz de restringir
norm(Ih_2h - 0.5*I2h_h') < 1e-12    # debe ser true
```
Verifica $I_h^{2h}=\frac12(I_{2h}^h)^T$ ([[Multigrid en 1D - transferencia e implementacion|eq. 5.23]]).

## (c) Cantidad de ciclos vs. $n$ ($ν=1$)

```julia
for L in 5:11
    N = 2^L - 1
    h = 1/(N+1)
    A = Ah(N)
    f = A * uexacta(N)
    u = zeros(N)
    k = 0
    while norm(f - A*u)/norm(f) > 1e-10
        u = vciclo(u, f, h, 1, 1)
        k += 1
    end
    println("L=$L  n=$N  ciclos=$k")
end
```
**No crece con $n$** - consistencia directa con el [[Multigrid en 1D - transferencia e implementacion|Teorema 5.34]] ($ρ$ independiente de $h$).

## (d) $ρ$ medido vs. $ν$

```julia
function rho_medido(N, nu; maxciclos=50, tol=1e-8)
    h = 1/(N+1)
    A = Ah(N)
    f = A * uexacta(N)
    nf = norm(f)
    u = zeros(N)
    prev = norm(f - A*u)
    ratio = NaN
    for _ in 1:maxciclos
        u = vciclo(u, f, h, nu, nu)
        cur = norm(f - A*u)
        cur/nf < tol && break    # parar ANTES de que el residuo caiga al piso de
                                   # precisión de punto flotante (~1e-11): más allá de
                                   # eso, el cociente deja de medir ρ y empieza a medir
                                   # ruido de redondeo (probarlo: con maxciclos grande
                                   # y sin este corte, salen cocientes >1, inestables)
        ratio = cur/prev
        prev = cur
    end
    return ratio
end

for nu in [1, 2, 3], L in [6, 9]
    N = 2^L - 1
    println("ν=$nu  L=$L  ρ≈", round(rho_medido(N, nu), digits=4))
end
```
```
ν=1  L=6  ρ≈0.1876        ν=1  L=9  ρ≈0.2012
ν=2  L=6  ρ≈0.0857        ν=2  L=9  ρ≈0.0913
ν=3  L=6  ρ≈0.0598        ν=3  L=9  ρ≈0.0607
```
El cociente $\|r_{k+1}\|_2/\|r_k\|_2$ se estabiliza en un valor $ρ$ que casi no depende de $L$ (es decir, de $h$: $0.19$ vs. $0.20$ para $ν=1$), y decrece al aumentar $ν$ ($0.19\to0.09\to0.06$) - exactamente lo que predice el Teorema 5.34 ("$ρ$ se puede hacer tan chico como se quiera aumentando $ν$").

## (e) Comparación con el suavizador solo

```julia
function barridos_necesarios(N, nu; maxbarridos=200_000)
    h = 1/(N+1)
    A = Ah(N)
    f = A * uexacta(N)
    u = zeros(N)
    k = 0
    while norm(f - A*u)/norm(f) > 1e-10 && k < maxbarridos
        u = jacobiamortiguado(u, f, h, nu)
        k += 1
    end
    return k
end

for L in 5:7      # L=8 (n=255) ya no converge dentro de 200_000 barridos - ver el porqué abajo
    N = 2^L - 1
    println("L=$L  n=$N  barridos de Jacobi solo=", barridos_necesarios(N, 1))
end
```
```
L=5  n=31   barridos de Jacobi solo=6918
L=6  n=63   barridos de Jacobi solo=27654
L=7  n=127  barridos de Jacobi solo=110568
```
Cada vez que $n$ se duplica, los barridos necesarios se multiplican por $\approx4$ ($6918\to27654\to110568$): confirma $O(n^2)$. A ese ritmo, $n=255$ ya necesitaría $\approx440000$ barridos - **sin corrección en malla gruesa**, por eso no converge dentro de los 200 000 del límite puesto arriba.

Sin corrección en malla gruesa (solo `jacobiamortiguado` repetido), la cantidad de barridos para la misma tolerancia **crece como $O(n^2)$** - porque el suavizador reduce rápido los modos oscilatorios pero casi no toca los modos suaves (ver [[Multigrid en 1D - problema modelo y suavizado]]), y sin la corrección en malla gruesa esos modos nunca se eliminan eficientemente.
