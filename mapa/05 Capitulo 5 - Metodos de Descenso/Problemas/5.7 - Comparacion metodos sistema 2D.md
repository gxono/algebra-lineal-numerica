# Problema 5.7 - Lo mismo que 5.5, en 2D (laplaciano de 5 puntos)

## Enunciado

> Consideramos el problema de hallar la función $u$ que satisface el siguiente problema de valores de borde
> $$\begin{cases}-\Delta u(x,y)=f(x,y), & (x,y)\in(0,1)\times(0,1)\\u(x,0)=u(x,1)=0, & x\in[0,1]\\u(0,y)=u(1,y)=0, & y\in[0,1]\end{cases}$$
> donde $f(x,y)=-2[x(x-1)+y(y-1)]$. Si consideramos una malla uniforme de tamaño $h=\frac1{N+1}$, sobre la que los nodos interiores se enumeran de izquierda a derecha y de abajo hacia arriba, la discretización de este problema por diferencias finitas se reduce a resolver el sistema $Ax=b$ donde $A$ es la matriz cuadrada de tamaño $N^2$ expresada en bloques como
> $$A = \begin{pmatrix}B&-I_N&&&\\-I_N&B&-I_N&&\\&-I_N&B&-I_N&\\&&\ddots&\ddots&\ddots\\&&&-I_N&B\end{pmatrix},$$
> donde la matriz $B$ de tamaño $N$ está dada por
> $$B = \begin{pmatrix}4&-1&&&\\-1&4&-1&&\\&-1&4&-1&\\&&\ddots&\ddots&\ddots\\&&&-1&4\end{pmatrix},$$
> e $I_N$ es la matriz identidad de orden $N$. Las componentes del vector de términos independientes $b$ son $h^2$ por el valor de $f$ en los correspondientes puntos de la grilla (enumerados de izquierda a derecha y de abajo hacia arriba).
>
> El vector solución $x$ aproxima los valores de la solución $u$ en los respectivos puntos de la grilla.
>
> Considerando distintos valores de $N$ ($N=10,50,100,\dots$), repetir los ítems (a), (b), (c) y (d) del [[5.5 - Comparacion metodos sistema 1D|Ejercicio 5.5]].

```julia
function laplaciano2d(N)
    n = N*N
    A = zeros(n,n)
    idx(i,j) = (j-1)*N + i
    for j in 1:N, i in 1:N
        k = idx(i,j)
        A[k,k] = 4.0
        i>1 && (A[k,idx(i-1,j)] = -1.0)
        i<N && (A[k,idx(i+1,j)] = -1.0)
        j>1 && (A[k,idx(i,j-1)] = -1.0)
        j<N && (A[k,idx(i,j+1)] = -1.0)
    end
    return A
end

N = 20
A = laplaciano2d(N)
f(x,y) = -2*(x*(x-1)+y*(y-1))
h = 1/(N+1)
b = [h^2*f(i*h,j*h) for j in 1:N for i in 1:N]
```
`A` y `b` quedan fijos para todo lo que sigue. Los seis métodos a comparar - [[Metodo de Jacobi|Jacobi]], [[Metodo de Gauss-Seidel|Gauss-Seidel]], [[Metodo SOR|SOR]], [[Metodo de Richardson|Richardson]], SD y GC - son los mismos del [[5.3 - Programar descenso y GC|Problema 5.3]] y del Capítulo 4; para SD/GC hace falta la versión instrumentada que además guarda el residuo en cada paso (mismo patrón que [[5.4 - Curvas de nivel ejemplo 2x2|Problema 5.4]] y [[5.5 - Comparacion metodos sistema 1D|Problema 5.5]](d)).

## Resultados numéricos ($N=20$, $n=N^2=400$)

```julia
κ = cond(A)                              # κ2(A), calculado directamente sobre la matriz

_, errJ  = jacobi(A, b; maxiter=20000)
_, errGS = gauss_seidel(A, b; maxiter=20000)
_, errSOR = SOR(A, b, 1.9; maxiter=20000)

λmin, λmax = eigmin(A), eigmax(A)
αopt = 2/(λmin + λmax)
_, errR = richardson(A, b, αopt; maxiter=20000)

function descmaspron_hist(A, b, x0; tol=1e-10, max_iter=200000)
    x = copy(x0)
    r = b - A*x
    err = Float64[]
    iter = 0
    while norm(r) > tol && iter < max_iter
        push!(err, norm(r))
        Ar = A*r
        α = (r'r)/(r'Ar)
        x += α*r
        r -= α*Ar
        iter += 1
    end
    return x, iter, err
end

function gradconj_hist(A, b, x0; tol=1e-10, max_iter=200000)
    x = copy(x0)
    r = b - A*x
    ρ = r'r
    d = copy(r)
    ρold = 0.0
    err = Float64[]
    iter = 0
    while sqrt(ρ) > tol && iter < max_iter
        push!(err, sqrt(ρ))
        if iter > 0
            β = ρ/ρold
            d = r + β*d
        end
        w = A*d
        α = ρ/(d'w)
        x += α*d
        r -= α*w
        ρold = ρ
        ρ = r'r
        iter += 1
    end
    return x, iter, err
end

xsd, itsd, errsd = descmaspron_hist(A, b, zeros(N^2))
xcg, itcg, errcg = gradconj_hist(A, b, zeros(N^2))

fig = Figure()
ax = Axis(fig[1, 1], yscale=log10, xlabel="iteración", ylabel="error / residuo (ver texto)")
lines!(ax, errJ, label="Jacobi (‖Δx‖₁)")
lines!(ax, errGS, label="Gauss-Seidel (‖Δx‖₁)")
lines!(ax, errSOR, label="SOR ω=1.9 (‖Δx‖₁)")
lines!(ax, 0:itsd-1, errsd, label="SD (‖r‖₂)")
lines!(ax, 0:itcg-1, errcg, label="GC (‖r‖₂)")
axislegend(ax)
save("cap5-comparacion-2d.png", fig)
```

> | Gauss-Seidel | $558$ |

$\kappa_2(A)=178.06$ para $N=20$ (verificado con `cond(A)`, consistente con $\kappa_2=O(h^{-2})=O(N^2)$: con $N=20$, $O(N^2)=400$, del mismo orden). La jerarquía es la misma que en 1D: **GC gana por un margen enorme** ($34$ iteraciones contra $1691$ de SD, $558$ de Gauss-Seidel, $1051$ de Jacobi/Richardson), y **SOR bien afinado** mejora mucho sobre Jacobi/GS pero sigue muy por detrás de GC.

El enunciado pide repetir los 4 items de [[5.5 - Comparacion metodos sistema 1D|Problema 5.5]] (cargar $A$/$b$, comparar Jacobi/GS/SOR, analizar Richardson con varios $α$, y GC/SD); el fenómeno **cualitativo** es el mismo que en 1D (mismo tipo de matriz, mismo $\kappa_2(A)=O(h^{-2})$, ver el análisis de Richardson con varios $\alpha$ en [[5.5 - Comparacion metodos sistema 1D|Problema 5.5]], que no hace falta repetir punto por punto acá), pero con los **números concretos de este problema 2D** arriba (no los de 1D, que son para otra matriz de otro tamaño).

## Conclusión

Igual que en 1D, $\kappa_2(A)=O(h^{-2})=O(N^2)$, así que las conclusiones de [[5.5 - Comparacion metodos sistema 1D|Problema 5.5]] se repiten cualitativamente, y los números de arriba lo confirman cuantitativamente para $N=20$: [[Metodo de Jacobi|Jacobi]]/GS/SD degradan con $N$; GC necesita muchas menos iteraciones. La diferencia en 2D es que $n=N^2$ (el tamaño del sistema crece cuadráticamente con $N$), así que el costo **total** de GC es $O(N)$ iteraciones $\times\, O(n)$ por iteración $=O(N^3)$, contra $O(N^2)$ iteraciones de un método estacionario $\times\,O(n)=O(N^4)$. La brecha entre GC y los estacionarios se agranda todavía más que en 1D.

Este es, de hecho, **exactamente** el sistema que se usa para ilustrar precondicionadores genéricos ([[Precondicionadores genericos|Cholesky incompleta]], con fill-in real a diferencia del caso 1D) - ver [[2.5 - Factorizacion LU tridiagonal|Problema 2.5]] (1D sin fill-in) vs. este caso (2D, con fill-in).
