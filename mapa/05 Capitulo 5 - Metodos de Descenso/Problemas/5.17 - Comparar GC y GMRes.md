# Problema 5.17 - Comparar GC y [[GMRes - definicion y propiedad de minimizacion|GMRes]] en el sistema del Problema 5.5

## Enunciado

> Comparar el comportamiento del método del gradiente conjugado y de GMRes para resolver el sistema lineal dado en el [[5.5 - Comparacion metodos sistema 1D|ejercicio 5.5]].

El sistema de [[5.5 - Comparacion metodos sistema 1D|Problema 5.5]] tiene $A_h$ **sdp**.

```julia
n = 100
A = Ah(n)
xstar = ones(n)
b = A*xstar  # mismo RHS genérico que en [[Tablas Comparativas - GC vs SD]]

_, itGC = gradconj(A, b, zeros(n))
_, itGMRes = gmres(A, b, zeros(n))
```
(Verificado numéricamente: `itGC=50`, `itGMRes=50` - exactamente iguales para este sistema, confirmando la conclusión de abajo.)

## ¿Qué se espera si $A$ es sdp?

Ambos minimizan sobre el mismo espacio de Krylov $\mathcal K_k$, pero en normas distintas (GC: norma $A$; GMRes: norma 2 del residuo). Para $A$ sdp, **GC es preferible**: tiene recurrencia de dos términos (memoria y costo por iteración constantes, [[Tablas Comparativas - GC vs GMRes]]), mientras que GMRes necesita guardar toda la base de Krylov (memoria y costo crecientes). En cuanto a **cantidad** de iteraciones, ambos están gobernados por el mismo tipo de cota en $\sqrt{\kappa_2(A)}$ (de hecho, para $A$ sdp, puede probarse que $GMRes$ converge en una cantidad de iteraciones comparable, a veces incluso igual, a la de GC), así que la diferencia práctica está casi enteramente en el costo **por** iteración, no en el número de iteraciones.

**Conclusión esperable:** número de iteraciones similar entre ambos (ninguno "gana" claramente ahí), pero GC es sustancialmente más barato en tiempo y memoria totales, porque no paga el costo creciente $O(nk)$ por iteración de GMRes. **Para $A$ sdp, no hay ninguna razón para usar GMRes en vez de GC** - GMRes se reserva para cuando $A$ no es simétrica.
