# Problema 5.11 - `gradconjp`, comparación con [[Precondicionadores genericos|Cholesky incompleta]]

## Enunciado

> **(a)** Modificar la función `gradconj` del [[5.3 - Programar descenso y GC|Ejercicio 5.3]] para implementar el método del gradiente conjugado precondicionado a través de la función `[x, iter, X] = gradconjp(A,b,precon,x0,tol,max_iter)`. Aquí, `precon` es el precondicionador a usar, dado como matriz en forma explícita o como una rutina que devuelve el producto matriz-vector para cada vector dado.
> **(b)** Comparar el comportamiento del método del gradiente conjugado usual y del método precondicionado con el precondicionador de Cholesky incompleto para la resolución del sistema del [[5.5 - Comparacion metodos sistema 1D|Ejercicio 5.5]] y/o [[5.7 - Comparacion metodos sistema 2D|5.7]].

## (a) `gradconjp`

```julia
function gradconjp(A, b, precon, x0; tol=1e-8, max_iter=1000)
    Av(v) = A isa Function ? A(v) : A * v
    Mv(v) = precon isa Function ? precon(v) : precon * v
    x = copy(x0)
    r = b - Av(x)
    z = Mv(r)
    ρ = r'z
    X = reshape(copy(x), :, 1)
    d = copy(z)
    ρold = 0.0
    iter = 0
    while norm(r) > tol && iter < max_iter
        if iter > 0
            β = ρ/ρold
            d = z + β*d
        end
        w = Av(d)
        α = ρ / (d'w)
        x += α*d
        r -= α*w
        z = Mv(r)
        ρold = ρ
        ρ = r'z
        X = hcat(X, x)
        iter += 1
    end
    return x, iter, X
end
```
Con $precon = v -> v$ se recupera `gradconj` del [[5.3 - Programar descenso y GC|Problema 5.3]].

## (b) Comparación con [[Factorizacion de Cholesky|Cholesky]] incompleta

Para el sistema **1D** tridiagonal ([[5.5 - Comparacion metodos sistema 1D|Problema 5.5]]), Cholesky no tiene fill-in: la factorización incompleta **coincide** con la completa, y el precondicionador es $M=A^{-1}$ **exacto** (no aproximado) - comparación degenerada, GCP converge en **exactamente 1 iteración**, para cualquier $x_0$.

> [!demostracion]- Por qué $M=A^{-1}$ exacto da convergencia en 1 iteración (para cualquier $x_0$)
> Sea $M=A^{-1}$ exactamente. En la primera iteración de `gradconjp`: $r_0=b-Ax_0$, $z_0=Mr_0=A^{-1}(b-Ax_0)=A^{-1}b-x_0=x_*-x_0$ - es decir, **el residuo precondicionado es exactamente el error** (cosa que en general no se puede calcular, porque no se conoce $x_*$, pero que $M=A^{-1}$ hace posible). La primera dirección es $d_1=z_0=x_*-x_0$.
>
> El paso es $\alpha_1=\dfrac{\rho_0}{d_1^TAd_1}$, con $\rho_0=r_0^Tz_0$. Usando $r_0=b-Ax_0=A(x_*-x_0)=Ad_1$ (porque $Ax_*=b$):
> $$\rho_0 = r_0^Tz_0 = (Ad_1)^Td_1 = d_1^TA^Td_1 = d_1^TAd_1$$
> (usando $A$ simétrica). Así, $\alpha_1=\dfrac{d_1^TAd_1}{d_1^TAd_1}=1$ - **siempre**, sin importar $x_0$ ni $b$. Entonces
> $$x_1 = x_0+\alpha_1d_1 = x_0+(x_*-x_0) = x_*.$$
> La solución exacta en el primer paso. Verificado numéricamente (`A` sdp densa aleatoria, no solo tridiagonal, con varios $x_0$ distintos): siempre 1 iteración, error $\sim10^{-15}$.

En la práctica $M$ nunca es $A^{-1}$ exacto (si lo fuera, ya se tendría la solución y no haría falta iterar) - acá sale exacto únicamente porque, en 1D, la factorización incompleta **coincide** con la completa (no hay fill-in que descartar). Es un caso límite que sirve para entender el mecanismo, no un resultado típico: el caso realista es el 2D de abajo, donde $M\neq A^{-1}$ y el precondicionador ayuda sin resolver de un solo golpe.

El caso interesante es el **2D** ([[5.7 - Comparacion metodos sistema 2D|Problema 5.7]]), donde sí hay fill-in real:

```julia
function icholesky(A)
    n = size(A,1)
    L = zeros(n,n)
    for k in 1:n
        L[k,k] = sqrt(A[k,k] - L[k,1:k-1]'*L[k,1:k-1])
        for i in k+1:n
            if A[i,k] != 0
                L[i,k] = (A[i,k] - L[i,1:k-1]'*L[k,1:k-1]) / L[k,k]
            end
        end
    end
    return LowerTriangular(L)
end
```

> [!comparacion]
> | $N$ | $n=N²$ | GC | GCP (Cholesky incompleta) |
> |---|---|---|---|
> | 8 | 64 | 10 | 12 |
> | 12 | 144 | 21 | 15 |
> | 16 | 256 | 30 | 19 |
> | 20 | 400 | 39 | 22 |
> | 24 | 576 | 47 | 25 |

Para $N$ chico, el precondicionador no ayuda; a medida que $N$ crece, GC crece $\approx O(N)$ (consistente con $\kappa_2(A)=O(N^2)$), mientras que GCP con Cholesky incompleta crece mucho más despacio - comportamiento típico de un precondicionador genérico: mejora la **constante**, pero no logra el $O(1)$ independiente de $N$ que sí logra [[Multigrid en 1D - transferencia e implementacion|multigrid]].
