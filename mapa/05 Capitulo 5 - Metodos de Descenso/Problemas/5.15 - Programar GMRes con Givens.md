# Problema 5.15 - Programar [[GMRes - definicion y propiedad de minimizacion|GMRes]] con [[Rotaciones de Givens|rotaciones de Givens]]

## Enunciado

> Programar el algoritmo de GMRes con las rotaciones de Givens para que sea lo más eficiente posible.

Implementación ya desarrollada en [[GMRes - implementacion y rotaciones de Givens]] (función `gmres`). Lo que pide el enunciado "lo más eficiente posible" está cubierto por: [[Ortogonalizacion de Gram-Schmidt|Gram-Schmidt]] **modificado** (estabilidad), y actualizar la factorización $QR$ de $H_k$ con rotaciones de Givens **incrementalmente** (costo $O(k)$ por iteración, no $O(k^2)$).

## Test de verificación clave

La `gmres` de [[GMRes - implementacion y rotaciones de Givens]] no devuelve $|g_{k+1}|$ (solo `x` y `k`); para comparar hace falta una versión instrumentada idéntica que además lo devuelva (mismo algoritmo, un solo valor extra en el `return`):

```julia
function gmres_debug(A, b, x0; tol=1e-8, kmax=length(b))
    Av(v) = A isa Function ? A(v) : A*v
    r0 = b - Av(x0)
    β = ρ = norm(r0)
    V = zeros(length(b), kmax+1)
    V[:,1] = r0/ρ
    H = zeros(kmax+1, kmax)
    g = zeros(kmax+1)
    g[1] = β
    c = zeros(kmax)
    s = zeros(kmax)
    k = 0
    while ρ > tol*norm(b) && k < kmax
        k += 1
        w = Av(V[:,k])
        for j in 1:k
            H[j,k] = w'V[:,j]
            w -= H[j,k]*V[:,j]
        end
        H[k+1,k] = norm(w)
        V[:,k+1] = w/H[k+1,k]
        for j in 1:k-1
            H[j:j+1,k] = [c[j] -s[j]; s[j] c[j]] * H[j:j+1,k]
        end
        ν = hypot(H[k,k], H[k+1,k])
        c[k] = H[k,k]/ν
        s[k] = -H[k+1,k]/ν
        H[k,k] = ν
        H[k+1,k] = 0
        g[k:k+1] = [c[k] -s[k]; s[k] c[k]] * g[k:k+1]
        ρ = abs(g[k+1])
    end
    y = UpperTriangular(H[1:k,1:k]) \ g[1:k]
    return x0 + V[:,1:k]*y, k, ρ
end

A = [4.0 1 0 0; 1 3 1 0; 0 1 2 1; 0 0 1 3]
b = [1.0, 2, 3, 4]
x, k, ρ_final = gmres_debug(A, b, zeros(size(A,1)))
@assert abs(norm(b - A*x) - ρ_final) < 1e-8   # g[k+1] debe coincidir con ‖b-Ax_k‖₂ real
```
$|g_{k+1}|$ (calculado **sin** formar $x_k$) debe coincidir, a precisión de máquina, con $\|b-Ax_k\|_2$ calculado directamente (verificado numéricamente: ambos $\approx10^{-16}$, diferencia $\approx10^{-15}$) - es el test de consistencia análogo al del [[5.12 - Multigrid como metodo iterativo|Problema 5.12]] para [[Multigrid en 1D - transferencia e implementacion|multigrid]].
