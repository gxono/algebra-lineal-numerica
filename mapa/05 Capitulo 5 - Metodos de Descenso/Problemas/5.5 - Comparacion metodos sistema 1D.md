# Problema 5.5 - [[Metodo de Jacobi|Jacobi]]/GS/[[Metodo SOR|SOR]]/[[Metodo de Richardson|Richardson]]/SD/GC en el problema modelo 1D

## Enunciado

> Consideramos el problema de hallar la función $u$ que satisface
> $$\begin{cases}-u''(x)=f(x), & x\in(0,1)\\u(0)=u(1)=0,\end{cases}$$
> donde $f(x)=\pi^2\text{sen}(\pi x)$. Se puede verificar fácilmente que la solución de este problema es $u(x)=\text{sen}(\pi x)$. Dada una partición del intervalo $[0,1]$ en $N+1$ intervalos de igual longitud $[x_0,x_1],[x_1,x_2],[x_2,x_3],\dots,[x_N,x_{N+1}]$ donde $x_0=0$ y $x_{N+1}=1$, la discretización de este problema por diferencias finitas se reduce a resolver el sistema $Ax=b$ donde $A$ es la matriz tridiagonal cuadrada de tamaño $N$ que tiene $2$ sobre la diagonal principal y $-1$ en las otras posiciones no-nulas, y el vector $b=h^2(f(x_1),f(x_2),\dots,f(x_N))^T$, donde $h=\frac1{N+1}$ es la longitud de cada subintervalo.
>
> El vector solución $x$ aproxima los valores de la solución $u$ en los puntos $x_1,x_2,\dots,x_N$, es decir, $x\approx(u(x_1),u(x_2),\dots,u(x_N))^T$.
>
> Considerando distintos valores de $N$ ($N=10,50,100,\dots$):
> **(a)** Cargar la matriz $A$ en formato sparse, utilizando la función `spdiags` de matlab/octave. Cargar también el vector de términos independientes $b$.
> **(b)** Utilizar los métodos de Jacobi, Gauss-Seidel y SOR para resolver el sistema lineal. Realizar un gráfico del error (en escala logarítmica) de cada método en función de la cantidad de iteraciones. Obtener conclusiones. Sugerencia: para calcular el error, utilizar como solución exacta la solución del sistema dada por el comando `\` de matlab/octave.
> **(c)** Analizar para diversos valores de $\alpha$ el comportamiento del método de Richardson. Comparar los resultados obtenidos en el ítem anterior.
> **(d)** Investigar el comportamiento de los métodos del descenso más pronunciado y del gradiente conjugado para resolver el sistema lineal.

El sistema es $(5.16)$: $A_hu=f$, $A_h=\frac1{h^2}\text{tridiag}(-1,2,-1)$ - ver [[Multigrid en 1D - problema modelo y suavizado]].

```julia
function Ah(N)
    h = 1/(N+1)
    SymTridiagonal(fill(2/h^2, N), fill(-1/h^2, N-1))
end

N = 100
A = Ah(N)
h = 1/(N+1)
f(x) = π^2*sin(π*x)
b = [f(i*h) for i in 1:N]
xtrue = A \ b

_, errJ  = jacobi(A, b; maxiter=20_000)
_, errGS = gauss_seidel(A, b; maxiter=20_000)
_, errSOR = SOR(A, b, 1.9; maxiter=20_000)        # ω cerca de 2 suele convenir para este problema

fig = Figure()
ax = Axis(fig[1, 1], yscale=log10, xlabel="iteración", ylabel="‖x_{k+1}-x_k‖₁")
lines!(ax, errJ, label="Jacobi")
lines!(ax, errGS, label="Gauss-Seidel")
lines!(ax, errSOR, label="SOR (ω=1.9)")
axislegend(ax)
save("cap5-jacobi-gs-sor.png", fig)
```
![[cap5-jacobi-gs-sor.png]]

Verificado (criterio de corte $\|x_{k+1}-x_k\|_1<10^{-6}$, tope $20000$ iteraciones): **Jacobi no llega a converger** en $20000$ iteraciones (sigue por encima de la tolerancia), **Gauss-Seidel** necesita $11409$, **SOR($\omega=1.9$)** solo $701$ - la jerarquía esperada (Jacobi el más lento, SOR bien afinado muchísimo mejor que los dos sin parámetro).

## (c) Richardson con varios $α$

$α_{\text{opt}}=2/(\lambda_{\min}+\lambda_{\max})$ queda, para este problema, casi pegado al límite de convergencia $2/\lambda_{\max}$ (porque $\lambda_{\min}\ll\lambda_{\max}$): alcanza con pasarse por un factor $\approx1.5$ para divergir.

![[cap5-richardson-varios-alpha.png]]

```julia
# requiere richardson - ver [[Metodo de Richardson]]
λmin, λmax = eigmin(A), eigmax(A)
αopt = 2/(λmin + λmax)
αs = [αopt*0.2, αopt*0.6, αopt, αopt*1.5, αopt*2.2]
labels = ["α=0.2·α_opt", "α=0.6·α_opt", "α=α_opt (óptimo)", "α=1.5·α_opt (diverge)", "α=2.2·α_opt (diverge más)"]

using CairoMakie
fig = Figure()
ax = Axis(fig[1, 1], yscale=log10, xlabel="iteración", ylabel="‖x_{k+1}-x_k‖₁")
for (α, lab) in zip(αs, labels)
    _, err = richardson(A, b, α; tol=1e-8, maxiter=3000)
    lines!(ax, err, label=lab)
end
axislegend(ax)
fig
```

Para $0<α<α_{\text{opt}}$, cuanto más chico el $α$, más lento (más lejos del óptimo); para $α$ apenas mayor que $α_{\text{opt}}$, diverge - acá no hay margen: $α_{\text{opt}}\approx4.90\times10^{-5}$ y el límite teórico $2/\lambda_{\max}\approx4.90\times10^{-5}$ son prácticamente el mismo número para esta matriz tan mal condicionada ($\lambda_{\min}\ll\lambda_{\max}$). Esto es justamente lo que motiva el descenso más pronunciado (recalcular $α$ en cada paso en vez de fijarlo de antemano, sin tener que "adivinar" un valor tan ajustado).

## (d) SD y GC

**Primero, un caso degenerado que hay que notar.** El $f(x)=\pi^2\text{sen}(\pi x)$ del enunciado hace que $b$ sea, exactamente, un múltiplo del primer autovector de $A$ (lo mismo que en [[Parcial Modelo - Problema 4]](g)):
```julia
f(x) = π^2*sin(π*x)
b = [f(i*h) for i in 1:N]
v1 = [sin(i*π*h) for i in 1:N]
b ./ v1    # -> constante (≈9.8696 = π²) para todo i: b es múltiplo de v1
```
Por el [[GC como metodo directo|Teorema 5.22]] (con $x_0=0$), GC converge en exactamente $1$ paso - y SD también, por la misma razón pero más simple: si $r_0=b$ ya es autovector de $A$, el paso óptimo $\alpha=r_0^Tr_0/r_0^TAr_0=1/\lambda_1$ resuelve el problema exactamente, porque moverse en la dirección de un autovector con el paso óptimo da la solución exacta en una sola dirección 1D. **Verificado: SD y GC ambos dan $1$ iteración**, con $\|x_1-x_*\|\approx5\times10^{-15}$.

Esto es informativo pero **no muestra el comportamiento típico** de SD/GC en función de $\kappa_2(A)$ que el ejercicio busca ilustrar (para eso hay que evitar que $b$ caiga justo en un autovector puro). Repitiendo con un lado derecho genérico ($x_*=(1,\dots,1)^T$, $b=Ax_*$, igual que en [[5.17 - Comparar GC y GMRes|Problema 5.17]]), con versiones instrumentadas que guardan el residuo (mismos algoritmos de [[Descenso mas pronunciado]] e [[Implementacion del gradiente conjugado]], solo agregando el `push!`):
```julia
function descmaspron_hist(A, b, x0; tol=1e-10, max_iter=200_000)
    x = copy(x0)
    r = b - A*x
    err = Float64[]
    iter = 0
    while norm(r) > tol && iter < max_iter
        push!(err, norm(r))
        Ar = A*r
        α = (r'r)/(r'Ar)
        x += α*r
        r -= α*Ar
        iter += 1
    end
    return x, iter, err
end

function gradconj_hist(A, b, x0; tol=1e-10, max_iter=200_000)
    x = copy(x0)
    r = b - A*x
    ρ = r'r
    d = copy(r)
    ρold = 0.0
    err = Float64[]
    iter = 0
    while sqrt(ρ) > tol && iter < max_iter
        push!(err, sqrt(ρ))
        if iter > 0
            β = ρ/ρold
            d = r + β*d
        end
        w = A*d
        α = ρ/(d'w)
        x += α*d
        r -= α*w
        ρold = ρ
        ρ = r'r
        iter += 1
    end
    return x, iter, err
end

for N in [100, 500, 1000]
    A = Matrix(Ah(N))
    xtrue = ones(N)
    b = A*xtrue
    _, itsd, _ = descmaspron_hist(A, b, zeros(N))   # tol=1e-10 en ‖r_k‖₂, max_iter=200_000
    _, itcg, _ = gradconj_hist(A, b, zeros(N))
    println("N=$N  κ2(A)=", cond(A), "  itSD=", itsd, "  itGC=", itcg)
end
```

```julia

A = Matrix(Ah(N))
xtrue = ones(N)
b = A*xtrue
xsd, itsd, errsd = descmaspron_hist(A, b, zeros(N))
xcg, itcg, errcg = gradconj_hist(A, b, zeros(N))

fig2 = Figure()
ax2 = Axis(fig2[1, 1], yscale=log10, xlabel="iteración", ylabel="‖r_k‖₂")
lines!(ax2, 0:itsd-1, errsd, label="SD ($itsd iter)")

```
![[cap5-sd-gc-1d.png]]

(Gráfico para $N=100$: SD necesita $57573$ iteraciones, GC solo $51$ - más de $1000$ veces menos.) Esto confirma cuantitativamente la jerarquía de la sección de Conclusión: **SD escala tan mal con $\kappa_2(A)=O(N^2)$ que ya no converge en $200000$ iteraciones para $N=500,1000$** (factor $\frac{\kappa-1}{\kappa+1}\to1$ demasiado rápido), mientras que **GC crece mucho más suave** ($51\to325\to1003$ para $N=100\to500\to1000$, consistente con $O(\sqrt\kappa)=O(N)$).

## Conclusión (consistente con la teoría ya establecida)

$\kappa_2(A_h)=O(h^{-2})=O(N^2)$ ([[Multigrid en 1D - problema modelo y suavizado]]). Por lo tanto:

- **Jacobi / [[Metodo de Gauss-Seidel|Gauss-Seidel]]:** $\rho(M)\to1$ cuando $N\to\infty$ (están gobernados por los modos suaves, que casi no se amortiguan) - convergencia muy lenta, empeora rápido con $N$.
- **SOR con $ω$ bien elegido** mejora bastante sobre Jacobi/GS, pero sigue degradándose con $N$ (no hay forma de evitar depender de $κ₂(A_h)$ sin usar la estructura).
- **Steepest descent:** factor $\frac{\kappa-1}{\kappa+1}\to1$: $O(N^2)$ iteraciones para tolerancia fija. El peor de todos para $N$ grande.
- **Gradiente conjugado:** factor $\frac{\sqrt\kappa-1}{\sqrt\kappa+1}$: $O(N)$ iteraciones - **mucho mejor** que los estacionarios y que SD, pero todavía crece con $N$ (sin precondicionar). Ver la comparación cuantitativa real en [[5.14 - Comparacion de los cuatro metodos|Problema 5.14]] (GC necesita exactamente $n$ iteraciones para $n=31,\dots,4095$ en los datos del profesor - crecimiento lineal confirmado).
