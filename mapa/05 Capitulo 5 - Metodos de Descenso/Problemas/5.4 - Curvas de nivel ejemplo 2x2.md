# Problema 5.4 - $A=\begin{bmatrix}2&1\\1&3\end{bmatrix}$, $b=(1,-2)$: curvas de nivel, SD vs. GC

## Enunciado

> Dada la matriz $A=\begin{pmatrix}2&1\\1&3\end{pmatrix}$ y el vector $b=\begin{pmatrix}1\\-2\end{pmatrix}$, dibujar las curvas de nivel de la energía del sistema $Ax=b$ y sus gradientes. Observar las direcciones de los mismos. Intentar determinar visualmente la posición del mínimo de dicha función.
> **(a)** Determinar la solución del sistema mediante el método del descenso más pronunciado, tratando de visualizar las aproximaciones y las direcciones que se toman en cada paso. Considerar una tolerancia de $10^{-3}$.
> **(b)** Determinar la solución del sistema mediante el método del gradiente conjugado, visualizando las aproximaciones y las direcciones que se toman en cada paso hasta llegar a la solución.

Solución exacta: $x_*=(1,-1)$. Autovalores $\lambda_{1,2}=\frac{5\mp\sqrt5}2\approx1.382,\,3.618$, $κ₂(A)=\frac{3+\sqrt5}2\approx2.618$. Como $A$ no es diagonal, las curvas de nivel son elipses **rotadas** (semieje mayor en dirección $\approx(1,-0.618)$, menor en $\approx(1,1.618)$, ortogonales).

```julia
using CairoMakie
A = [2.0 1.0; 1.0 3.0]
b = [1.0, -2.0]
φ(x,y) = 0.5*(2x^2+2x*y+3y^2) - (x - 2y)
xs = range(-1,3,length=150)
ys = range(-3,1,length=150)
fig = Figure()
ax = Axis(fig[1, 1])
contour!(ax, xs, ys, φ; levels=25)
scatter!(ax, [1], [-1])
fig
```

**(a) SD desde $x0=(0,0)$, $tol=10^{-3}$: 9 iteraciones**, con el zigzag característico ($r_k\perp r_{k-1}$): iteraciones impares caen exactamente sobre $y=-1$, pares se acercan por la diagonal $y=-x$.

**(b) GC desde el mismo $x0$: 2 iteraciones** (exacto), porque $A$ tiene solo 2 autovalores distintos ([[GC como metodo directo|Teorema 5.21]]). El primer paso coincide con SD ($d_1=r_0$ en ambos), pero GC llega exacto en el segundo paso.

`descmaspron`/`gradconj` ([[Descenso mas pronunciado]], [[Implementacion del gradiente conjugado]]) no guardan el historial de iterados; para el gráfico de zigzag hace falta una versión instrumentada que sí lo haga (mismo algoritmo, solo agrega el `push!` a una lista):

```julia
function descmaspron_full(A, b, x0; tol=1e-8, max_iter=1000)
    x = copy(x0)
    r = b - A*x
    X = [copy(x)]
    iter = 0
    while norm(r) > tol && iter < max_iter
        Ar = A*r
        α = (r'r) / (r'Ar)
        x += α*r
        r -= α*Ar
        iter += 1
        push!(X, copy(x))
    end
    return x, iter, X
end

function gradconj_full(A, b, x0; tol=1e-8, max_iter=1000)
    x = copy(x0)
    r = b - A*x
    ρ = r'r
    d = copy(r)
    ρold = 0.0
    iter = 0
    X = [copy(x)]
    while sqrt(ρ) > tol && iter < max_iter
        if iter > 0
            β = ρ/ρold
            d = r + β*d
        end
        w = A*d
        α = ρ/(d'w)
        x += α*d
        r -= α*w
        ρold = ρ
        ρ = r'r
        iter += 1
        push!(X, copy(x))
    end
    return x, iter, X
end

xsd, itsd, Xsd = descmaspron_full(A, b, [0.0,0.0]; tol=1e-3)   # itsd = 9
xcg, itcg, Xcg = gradconj_full(A, b, [0.0,0.0]; tol=1e-3)       # itcg = 2, xcg=(1,-1)

Xsd_x, Xsd_y = [p[1] for p in Xsd], [p[2] for p in Xsd]
Xcg_x, Xcg_y = [p[1] for p in Xcg], [p[2] for p in Xcg]

fig = Figure(size=(900,450))
ax1 = Axis(fig[1,1], title="Descenso más pronunciado (9 iter)", xlabel="x", ylabel="y")
contour!(ax1, xs, ys, φ; levels=25)
lines!(ax1, Xsd_x, Xsd_y, color=:red)
scatter!(ax1, Xsd_x, Xsd_y, color=:red, markersize=10)
scatter!(ax1, [1], [-1], color=:black, marker=:star5, markersize=16)

ax2 = Axis(fig[1,2], title="Gradiente conjugado (2 iter)", xlabel="x", ylabel="y")
contour!(ax2, xs, ys, φ; levels=25)
lines!(ax2, Xcg_x, Xcg_y, color=:blue)
scatter!(ax2, Xcg_x, Xcg_y, color=:blue, markersize=10)
scatter!(ax2, [1], [-1], color=:black, marker=:star5, markersize=16)

save("cap5-curvas-nivel-sd-gc.png", fig)
```
