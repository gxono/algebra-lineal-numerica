# Problema 5.13 - Multigrid como precondicionador del GC

## Enunciado

> (Multigrid como precondicionador del gradiente conjugado.) Usando las funciones del [[5.12 - Multigrid como metodo iterativo|Problema 5.12]] y la implementación del gradiente conjugado precondicionado de la Sección 5.6, tomar como precondicionador la acción $\xi\mapsto M\xi=\text{vciclo}(0,\xi,h,\nu,\nu)$, es decir, un ciclo en V con dato inicial nulo.
> **(a)** Construir la matriz $M$ aplicando esa acción a los vectores de la base canónica (para $n$ chico, digamos $n=31$). Verificar numéricamente que $M$ es simétrica cuando $\nu_1=\nu_2$, y que deja de serlo si se toma $\nu_1\neq\nu_2$. ¿Por qué importa?
> **(b)** Calcular $\sigma(MA_h)$ y verificar que está contenido en un intervalo alrededor de 1. Comparar $\kappa_2(MA_h)=c_2/c_1$ con la cota $\frac{1+\rho}{1-\rho}$ de (5.27), usando el $\rho$ medido en el Problema 5.12(d).
> **(c)** Resolver el sistema con gradiente conjugado precondicionado, con la misma tolerancia que antes, para $L=5,6,\dots,12$. Verificar que la cantidad de iteraciones no crece con $n$. Comparar $\nu=1$ con $\nu=2$.
> **(d)** Verificar que la cota de error del gradiente conjugado precondicionado, con el $c_2/c_1$ medido en (b), es consistente con la cantidad de iteraciones observada.

Precondicionador: $ξ\mapsto M\xi:=\text{vciclo}(0,\xi,h,\nu,\nu)$ (un ciclo en V con dato inicial nulo).

## (a) Construir $M$ explícitamente (chico, $n=31$) y verificar simetría

```julia
using LinearAlgebra

function canonico(n, j)   # evita la ambigüedad de I(n) (ver Problema 5.12b)
    e = zeros(n)
    e[j] = 1.0
    return e
end

Mmatriz(n, h, ν1, ν2) = hcat([vciclo(zeros(n), canonico(n, j), h, ν1, ν2) for j in 1:n]...)

n = 31
h = 1/(n+1)
M_eq  = Mmatriz(n, h, 1, 1)    # ν1=ν2=1
M_neq = Mmatriz(n, h, 1, 2)    # ν1=1, ν2=2

norm(M_eq - M_eq')             # -> 1.39e-17  (simétrica, a precisión de máquina)
norm(M_neq - M_neq')           # -> 7.32e-4   (NO simétrica, ni cerca)
```
Verificado: con $ν_1=ν_2=1$, $\|M-M^T\|\approx1.4\times10^{-17}$ (simétrica); con $ν_1=1,ν_2=2$, $\|M-M^T\|\approx7.3\times10^{-4}$ (claramente no simétrica, no es ruido de redondeo).

**Por qué importa:** $M$ es simétrica **solo si $ν₁=ν₂$**: la relación variacional $I_h^{2h}=\frac12(I_{2h}^h)^T$ es lo que garantiza que el operador de dos mallas sea simétrico, pero eso por sí solo no simetriza el ciclo completo si el número de barridos de pre/post-suavizado es distinto - hace falta que la "rama de bajada" (pre-suavizado) sea la imagen especular de la "rama de subida" (post-suavizado). Esto importa porque [[Implementacion del gradiente conjugado|GC]] (y el [[5.10 - Cota de kappa2 SAS|Problema 5.10]] que justifica el GCP) necesitan $M$ sdp - con $ν_1\neq ν_2$ se pierde esa garantía y GCP deja de tener sentido teórico (aunque numéricamente "funcione" por accidente en algún caso).

## (b) $σ(MA_h)$ y comparación con la cota $(1+ρ)/(1-ρ)$

```julia
evs = eigvals(M_eq * Matrix(Ah(n)))
extrema(evs)                        # -> (0.8104, 1.0000)
c1, c2 = extrema(evs)
κ2_MAh = c2/c1                      # -> 1.2339

# ρ medido en 5.12(d), adaptado a n=31 (L=5), ν=1 (mismo código que esa página)
function rho_medido(N, nu; maxciclos=50, tol=1e-8)
    hh = 1/(N+1)
    AA = Matrix(Ah(N))
    f = AA * uexacta(N)
    nf = norm(f)
    u = zeros(N)
    prev = norm(f - AA*u)
    ratio = NaN
    for _ in 1:maxciclos
        u = vciclo(u, f, hh, nu, nu)
        cur = norm(f - AA*u)
        cur/nf < tol && break
        ratio = cur/prev
        prev = cur
    end
    return ratio
end
ρ = rho_medido(31, 1)                # -> 0.1826
cota = (1+ρ)/(1-ρ)                   # -> 1.4469
```
Verificado: $\sigma(MA_h)\subset[0.8104,\,1.0000]\subset[1-\rho,1+\rho]=[0.8174,1.1826]$ (el intervalo teórico es ligeramente más ancho, consistente con que es una cota, no un valor exacto). $\kappa_2(MA_h)=c_2/c_1=1.2339$, y la cota $(1+\rho)/(1-\rho)=1.4469$ con el $\rho=0.1826$ medido - **la cota real es menor que la cota teórica** ($1.2339<1.4469$), confirmando [[Multigrid en 1D - transferencia e implementacion|eq. (5.27)]].

## (c) $κ₂(MA_h)$ no crece con $n$

```julia
function kappa2_MAh(N, nu)
    hh = 1/(N+1)
    Mm = Mmatriz(N, hh, nu, nu)
    Mm = (Mm + Mm')/2          # simétrica en teoría (ν1=ν2); limpia ruido de redondeo
    ev = eigvals(Mm * Matrix(Ah(N)))
    evr = real.(ev)            # parte imaginaria es ruido de redondeo (<1e-8), descartable
    return maximum(evr)/minimum(evr)
end

for L in 5:9
    N = 2^L - 1
    println("L=$L  n=$N  κ2(MA)[ν=1]=", kappa2_MAh(N,1), "  κ2(MA)[ν=2]=", kappa2_MAh(N,2))
end
```
```
L=5  n=31   κ2(MA)[ν=1]=1.2339  κ2(MA)[ν=2]=1.0961
L=6  n=63   κ2(MA)[ν=1]=1.2358  κ2(MA)[ν=2]=1.0967
L=7  n=127  κ2(MA)[ν=1]=1.2402  κ2(MA)[ν=2]=1.0971
L=8  n=255  κ2(MA)[ν=1]=1.2411  κ2(MA)[ν=2]=1.0974
L=9  n=511  κ2(MA)[ν=1]=1.2419  κ2(MA)[ν=2]=1.0976
```
(Se para en $L=9$: construir $M$ explícitamente cuesta $O(n)$ ciclos en V, cada uno $O(n)$, y además `eigvals` sobre la matriz densa $n\times n$ es $O(n^3)$ - para $L=10,11,12$ ($n=1023,\dots,4095$) ya no vale la pena solo para verificar algo que estos 5 valores ya muestran con claridad.) **No crece con $n$** - consistente con [[Multigrid en 1D - transferencia e implementacion|eq. (5.27)]]: $\kappa_2(SA_hS)\leq\frac{1+\rho}{1-\rho}$, independiente de $h$. Comparando $ν=1$ con $ν=2$: más barridos → $ρ$ más chico (ver [[5.12 - Multigrid como metodo iterativo|Problema 5.12]](d): $\rho\approx0.19$ vs. $\approx0.09$) → $κ₂(MA)$ más chico ($\approx1.24$ vs. $\approx1.10$), pero cada ciclo cuesta el doble de barridos de suavizado.

## (d) Consistencia entre la cota de error y las iteraciones observadas

```julia
for (ν, k_obs) in [(1, 8), (2, 6)]       # k_obs: iteraciones reales de 5.14, n=31
    κ = kappa2_MAh(31, ν)
    r = (sqrt(κ)-1)/(sqrt(κ)+1)
    k_pred = ceil(Int, log(1e-10/2)/log(r))    # de la cota 2r^k ≤ 1e-10
    println("ν=$ν  κ2(MA)=", κ, "  k predicho=", k_pred, "  k observado (5.14)=", k_obs)
end
```
```
ν=1  κ2(MA)=1.2339  k predicho=9  k observado (5.14)=8
ν=2  κ2(MA)=1.0961  k predicho=7  k observado (5.14)=6
```
La cota predice $1$ iteración más que la observada en ambos casos ($9$ vs. $8$, $7$ vs. $6$) - totalmente razonable: es una cota superior (Teorema 5.19 vía el $c_2/c_1$ de este problema), no un valor exacto, y la sobreestima por un margen chico y consistente. Confirma que el GCP de [[5.14 - Comparacion de los cuatro metodos|Problema 5.14]] se comporta exactamente como predice la teoría de este problema.
