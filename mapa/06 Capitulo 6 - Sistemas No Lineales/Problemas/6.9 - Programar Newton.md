# Problema 6.9 - Programar `newton`

## Enunciado

> Considerar un sistema no lineal $F(x)=0$, donde $F:D\subset\mathbb{R}^n\to\mathbb{R}^n$. Escribir una función `[x,iter,X]=newton(F, DF, x0, miter,tol)` para resolver el sistema por el método de Newton. Los parámetros de entrada son una referencia `F` a la función $F(x)$, una referencia `DF` a la matriz jacobiana $F'(x)$, un punto inicial `x0`, el máximo número de iteraciones permitido `miter` y una tolerancia `tol` permitida. Los parámetros de salida son la aproximación `x` de una solución del sistema, la cantidad de iteraciones realizadas `iter` y la matriz `X` cuyas columnas son las sucesivas aproximaciones que se calcularon.
> *Sugerencia:* Para resolver el sistema lineal necesario en cada iteración utilizar el comando "$\backslash$" de MATLAB/OCTAVE.

## Mi implementación (cuaderno del Capítulo 6)

```julia
"""
	newton(F, DF, x0, miter, tol)
"""
function newton(F, DF, x0, miter, tol)
	Ⅎ(v) = DF(v...) \ F(v...)          # paso de Newton h = F'(v)⁻¹F(v), resolviendo el sistema
	X = Matrix{Float64}(undef, length(x0), miter)

	X[:, 1] = x0
	k = 1

	while k < miter
		y = Ⅎ(X[:, k])
		X[:, k+1] = X[:, k] - y
		k += 1

		norm(y) < tol && break           # criterio: paso ‖h‖ < tol
	end

	return X[:,k], k-1, X[:, 1:k]
end
```

Convenciones de esta versión:
- `F` y `DF` reciben las **coordenadas sueltas** (`F(x, y)`, `DF(x, y)`), por eso el `v...` (splat).
- `iter = k-1` es la cantidad de **pasos de Newton** hechos; `X` tiene `iter+1` columnas ($x_0,\dots,x_{\text{iter}}$).
- Se para cuando $\|h\|=\|x_{k+1}-x_k\|<$ `tol`, y ese último paso **se incluye** (el error real suele ser mucho menor que `tol`, porque con convergencia cuadrática $\|x_{k+1}-x_*\|\approx C\|h\|^2$).

> [!pendiente] Detalles a cuidar
> - Si se llega a `miter` sin cumplir la tolerancia, la función devuelve el último iterado **sin avisar**. Conviene un `@warn` (ver la versión de abajo).
> - Usar `\`, nunca `inv(DF(...)) * F(...)`: más caro y menos estable ([[Resolver sistemas lineales en Julia]]).
> - Un criterio más robusto combina paso y residuo: `norm(h) < tol || norm(F(x)) < tol`.

## Versión con vectores y aviso

La que se usa en el resto de los problemas del capítulo cuando `F` recibe un vector:

```julia
function newton_vec(F, DF, x0; miter=50, tol=1e-12)
    X = [x0]; x = x0
    for k in 1:miter
        h = DF(x) \ F(x)
        x = x - h
        push!(X, x)
        norm(h) < tol && return x, k, reduce(hcat, X)
    end
    @warn "Newton: no convergió en $miter iteraciones"
    return x, miter, reduce(hcat, X)
end
```

Funciona igual con `BigFloat` (útil para medir el orden de convergencia, ver [[6.10 - Orden experimental de Newton|Problema 6.10]]).
