# Problema 7.3 - Programar las potencias inversas y verificar la tasa

## Enunciado

> Programar el método de las potencias inversas y verificar la tasa de convergencia con una matriz de $5\times5$ de la que conozca los autovalores.

## Implementación

```julia
function potencias_inversas(A, u0, μ; tol=1e-10, kmax=10_000)
    F = lu(A - μ*I)                    # una sola factorización
    u = u0 / norm(u0); v = F \ u
    λs = Float64[]; us = Vector{Float64}[]
    k = 0
    while true
        k += 1
        u = v / norm(v)
        v = F \ u                      # v_{k+1} = (A - μI)⁻¹ u_k
        θ = dot(u, v)                  # cociente de Rayleigh de (A-μI)⁻¹
        λ = 1/θ + μ
        push!(λs, λ); push!(us, u)
        (norm(v - θ*u) ≤ tol*abs(θ) || k == kmax) && break
    end
    return λs[end], u, k, λs, us
end
```

## Experimento

Simétrica $A=Q\,\text{diag}(10,8,4,2,1)\,Q^T$ (la del [[7.1 - Programar el metodo de las potencias|Problema 7.1]]). Tasa teórica ([[Proposicion 7.7]]): $\rho_\mu=\dfrac{|\lambda_*-\mu|}{\min_{\lambda_i\neq\lambda_*}|\lambda_i-\mu|}$, donde $\lambda_*$ es el autovalor más cercano a $\mu$.

| $\mu$ | converge a | $\rho_\mu$ teórica | tasa medida (autovector) | tasa medida (autovalor) | iteraciones ($10^{-13}$) |
|---|---|---|---|---|---|
| 3.8 | 4 | $0.2/1.8=0.1111$ | $0.105\to0.110$ | $0.011\to0.012\approx\rho_\mu^2$ | 14 |
| 3.5 | 4 | $0.5/1.5=0.3333$ | $0.319\to0.331$ | $0.103\to0.108\approx\rho_\mu^2$ | 27 |
| 7.9 | 8 | $0.1/2.1=0.0476$ | $0.044\to0.047$ | $0.0019\to0.0022\approx\rho_\mu^2$ | 11 |

**Conclusiones:**
- La tasa medida tiende a $\rho_\mu$ (y su cuadrado para el autovalor, por ser simétrica).
- **El shift controla la velocidad:** acercar $\mu$ de $3.5$ a $3.8$ baja $\rho_\mu$ de $1/3$ a $1/9$ y la cantidad de iteraciones a la mitad.
- Con $\mu=7.9$ se obtiene $\lambda=8$, que **no** es el dominante: las potencias inversas encuentran **cualquier** autovalor si se tiene una aproximación.
