# Problema 7.1 - Programar el método de las potencias y verificar la tasa

## Enunciado

> Programar el método de las potencias y verificar la tasa de convergencia con una matriz de $5\times5$ de la que conozca los autovalores.

## Implementación

La del apunte (un solo producto matriz-vector por paso, residuo gratis), guardando la historia para medir tasas:

```julia
function potencias(A, u0; tol=1e-10, kmax=10_000)
    u = u0 / norm(u0); v = A*u
    μs = Float64[]; us = Vector{Float64}[]
    k = 0
    while true
        k += 1
        u = v / norm(v)
        v = A*u
        μ = dot(u, v)                 # u_kᴴ A u_k
        r = v - μ*u                   # A u_k - μ_k u_k
        push!(μs, μ); push!(us, u)
        (norm(r) ≤ tol*abs(μ) || k == kmax) && break
    end
    return μs[end], u, k, μs, us
end
```

## Matrices de prueba con autovalores conocidos

$\lambda=(10,8,4,2,1)$, así que la tasa teórica es $|\lambda_2/\lambda_1|=0.8$.
- **Simétrica:** $A=Q\,\text{diag}(\lambda)\,Q^T$ con $Q$ ortogonal al azar (`Matrix(qr(randn(5,5)).Q)`).
- **No simétrica:** $A=V\,\text{diag}(\lambda)\,V^{-1}$ con $V$ al azar.

```julia
λ = [10.0, 8, 4, 2, 1]
Q = Matrix(qr(randn(5,5)).Q);  As = Q*Diagonal(λ)*Q'
V = randn(5,5);                 An = V*Diagonal(λ)/V
μ, u, k, μs, us = potencias(As, randn(5); tol=1e-12)
ev = [min(norm(w - Q[:,1]), norm(w + Q[:,1])) for w in us]   # error en dirección (signo libre)
ev[2:end] ./ ev[1:end-1]                                      # → 0.8
```

## Resultados

| | iteraciones ($\text{tol}=10^{-12}$) | tasa medida autovector | tasa medida autovalor |
|---|---|---|---|
| simétrica | 109 | $0.8000$ | $0.6400=0.8^2$ |
| no simétrica | 117 | $0.8002$–$0.8004$ | $0.791\to0.796$ ($\to0.8$) |

![[cap7-potencias-7.1.png]]

**Conclusiones:**
- El **autovector** converge con tasa $|\lambda_2/\lambda_1|=0.8$ en los dos casos, como dice la [[Proposicion 7.2]].
- El **autovalor** (cociente de Rayleigh) converge con tasa $0.8^2=0.64$ si $A$ es **simétrica** (error cuadrático del cociente de Rayleigh, [[Observacion 7.4]]) y con tasa $0.8$ si no lo es.
- En la simétrica, el error del autovalor toca el piso $\sim10^{-15}$ mucho antes que el del autovector: con el criterio $\|r_k\|\leq\text{tol}|\mu_k|$ se sigue iterando porque $\|r_k\|$ va como el error del **autovector**.
- El error del autovector se mide **en dirección** ($\min(\|u_k-x_1\|,\|u_k+x_1\|)$), porque $u_k$ solo converge salvo signo.
