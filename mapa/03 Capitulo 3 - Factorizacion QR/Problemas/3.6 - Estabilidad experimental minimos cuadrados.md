# Problema 3.6 - Comparación experimental: `mincuad`, `mincuadqr`, `\`

## Enunciado

> Analizar experimentalmente la velocidad y la precisión (o estabilidad) de las funciones `mincuad(A,b)`, `mincuadqr(A,b)` y `\` (de matlab/octave) al resolver el siguiente problema de mínimos cuadrados: $Ax=b$ donde $A\in\mathbb R^{n\times4}$ es la matriz `A = [a.^3, a.^2, a, ones(n,1)]` para `a = linspace(1,5,n)'`, y el vector $b$ elegido de manera que la solución exacta del problema sea $x=(1,1,1,1)^T$. Considerar distintos valores grandes de $n$.

> [!idea]
> Confirmación numérica de [[Estabilidad y numero de condicion]]: con una matriz de Vandermonde moderadamente mal condicionada, las ecuaciones normales pierden sistemáticamente 2-3 órdenes de magnitud de precisión frente a `A\b`.

## Setup

`A = [a.^3 a.^2 a ones(n,1)]` con `a = range(1,5,length=n)`, y $b$ elegido de manera que la solución exacta sea $x=(1,1,1,1)$ (es decir, $b=A*[1,1,1,1]$).

```julia
using LinearAlgebra

function mincuad(A, b)
    F = cholesky(Symmetric(A'A))
    return F \ (A'b)
end

for n in [20, 200, 2000]
    a = range(1, 5, length=n)
    A = [a.^3 a.^2 a ones(n)]
    xtrue = ones(4)
    b = A * xtrue

    x_normales = mincuad(Matrix(A), b)
    x_qr       = mincuadqr(Matrix(A), b)[1]
    x_backslash = A \ b

    @show n, cond(Matrix(A))
    @show norm(x_normales - xtrue), norm(x_qr - xtrue), norm(x_backslash - xtrue)
end
```

## Resultado (valores reales obtenidos corriendo el código)

> [!comparacion]
> | $n$ | $κ₂(A)$ | error ecuaciones normales | error `A\b` (QR) |
> |---|---|---|---|
> | 20 | ≈1387 | $1.3\times10^{-11}$ | $1.6\times10^{-13}$ |
> | 200 | ≈1524 | $2.8\times10^{-11}$ | $1.1\times10^{-14}$ |
> | 2000 | ≈1540 | $3.3\times10^{-11}$ | $5.0\times10^{-14}$ |

## Conclusiones

- $κ₂(A)$ se estabiliza alrededor de $1500$ (no depende fuertemente de $n$ para este rango fijo $[1,5]$), así que **no** es $n$ lo que degrada la precisión, sino el condicionamiento intrínseco de la matriz de Vandermonde.
- El error de las **ecuaciones normales** es consistentemente **2 a 3 órdenes de magnitud mayor** que el de `A\b` (que internamente usa QR, equivalente a `mincuadqr`), confirmando la predicción teórica $\kappa_2(A)^2\varepsilon_{maq}$ vs. $\kappa_2(A)\varepsilon_{maq}$.
- Si se agranda el rango de $a$ (por ejemplo `range(1,20,length=n)`), $κ₂(A)$ crece mucho más (las potencias $a^3$ dominan cada vez más), y la brecha entre ambos métodos se agranda todavía más - es un buen experimento adicional para visualizar el fenómeno de forma más dramática.
