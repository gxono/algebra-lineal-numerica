# Problema 2.5 - Factorización [[Factorizacion LU|LU]] de una matriz tridiagonal

## Enunciado

> Crear la función `[l,u] = tridilu(d,dmenos,dmas)` que calcule la factorización LU sin pivoteo de una matriz tridiagonal $A$ donde
> $$A = \text{diag}(dmenos(2:n),-1) + \text{diag}(d) + \text{diag}(dmas(1:n-1),1).$$
> Los vectores $l$ y $u$ son tales que
> $$L = \text{diag}(ones(n,1)) + \text{diag}(l(2:n),-1), \qquad U = \text{diag}(u) + \text{diag}(dmas(1:n-1),1).$$
> Además:
> **(a)** Realizar el conteo de operaciones realizadas por `tridilu` y comparar con la cantidad de operaciones realizadas por la función `eleu` desarrollada en clase.
> **(b)** Crear las funciones `triinfbidi` y `trisupbidi` para resolver sistemas triangulares bidiagonales, donde los argumentos de entrada sean vectores.
> **(c)** Considerar un sistema lineal asociado a la matriz $A$ de $N\times N$ ($N=100,1000,10000$) donde
> $$A = \begin{pmatrix}2&-1&&&\\-1&2&-1&&\\&-1&2&-1&\\&&\ddots&\ddots&\ddots\\&&&-1&2\end{pmatrix}.$$
> Comparar los tiempos necesarios para hallar la solución del sistema utilizando las funciones `eleu`, `triinf_cols` y `trisup` por un lado, y `tridilu`, `triinfbidi` y `trisupbidi` por otro lado.

> [!idea]
> Una matriz tridiagonal $A = tridiag(dmenos, d, dmas)$ tiene factorización LU **sin fill-in**: $L$ y $U$ son bidiagonales. El costo baja de $O(n³)$ a $O(n)$. Esta es la primera vez que aparece la idea de "explotar la estructura sparse", que es central en el Capítulo 5 ([[Multigrid en 1D - transferencia e implementacion|multigrid]]).

## (a) `tridilu`: factorización LU tridiagonal

Como solo hay que hacer ceros en la subdiagonal `dmenos`, los únicos multiplicadores de $L$ quedan en la misma diagonal (no hay fill-in), y la sobre-diagonal de $U$ coincide con `dmas` (nunca se modifica, porque el elemento de encima de cada pivote ya es cero).

```julia
"""
    tridilu(A::Tridiagonal)

Factorización LU sin pivoteo de una matriz tridiagonal.
Devuelve l (subdiagonal de L, unitaria en la diagonal) y u (diagonal de U).
"""
function tridilu(A::Tridiagonal)
    n = size(A, 1)
    l = Vector{Float64}(undef, n-1)
    u = Vector{Float64}(undef, n)
    u[1] = A.d[1]
    @inbounds for i in 1:n-1
        l[i] = A.dl[i] / u[i]
        u[i+1] = A.d[i+1] - l[i] * A.du[i]
    end
    return l, u
end
```

**Conteo de operaciones:** por cada $i$ se hacen 1 división, 1 multiplicación, 1 resta: $3(n-1) = O(n)$ operaciones en total, contra $≅2n³/3$ de `eleu` sobre la matriz densa. La diferencia es enorme y crece con $n$.

## (b) Sistemas bidiagonales

```julia
"""
    triinfbidi(dp, ds, b)

Resuelve Lx=b con L bidiagonal inferior: dp es la diagonal principal,
ds es la subdiagonal.
"""
function triinfbidi(dp::Vector, ds::Vector, b::Vector)
    x = similar(b)
    x[1] = b[1] / dp[1]
    for i in 2:length(b)
        x[i] = (b[i] - x[i-1] * ds[i-1]) / dp[i]
    end
    return x
end

"""
    trisupbidi(dp, ds, b)

Resuelve Ux=b con U bidiagonal superior: dp es la diagonal principal,
ds es la sobre-diagonal.
"""
function trisupbidi(dp::Vector, ds::Vector, b::Vector)
    x = similar(b)
    n = length(b)
    x[n] = b[n] / dp[n]
    for i in n-1:-1:1
        x[i] = (b[i] - x[i+1] * ds[i]) / dp[i]
    end
    return x
end
```

Cada una cuesta $O(n)$ (un solo `for`, 3 operaciones por paso).

## (c) Comparación de tiempos: denso vs. estructura tridiagonal

> [!comparacion]
> | $N$ | `eleu` (densa) | `tridilu` (estructura) |
> |---|---|---|
> | 100 | $O(10^6)$ op. | $O(10^2)$ op. |
> | 1000 | $O(10^9)$ op. | $O(10^3)$ op. |
> | 10000 | $O(10^{12})$ op. | $O(10^4)$ op. |
>
> (órdenes de magnitud; la relación exacta es $2N³/3$ vs. $3(N-1)$). Al duplicar $N$, el costo denso se multiplica por $8$, mientras que el tridiagonal apenas se duplica. Para $N=10000$, la versión densa ya es completamente impracticable (requeriría ≈67 mil millones de operaciones), mientras que la tridiagonal corre instantáneamente.

```julia
using BenchmarkTools
N = 1000
A = Tridiagonal(fill(-1.0, N-1), fill(2.0, N), fill(-1.0, N-1))
Ad = Matrix(A)
@benchmark eleu($Ad)        # denso: ~ms, crece como N³
@benchmark tridilu($A)      # estructurado: ~μs, crece como N
```
